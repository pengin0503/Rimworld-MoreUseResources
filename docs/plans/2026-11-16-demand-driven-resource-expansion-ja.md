# 実データを使うリソース活用の拡張

対象は RimWorld Windows 1.7.5011 rev24、Waylith、既存の PR #5。
WOWGAG、Axen、Overclock と併用する。ゲーム進行と各MODの設定に手を加えず、実アセット読み込みと常駐の処理量を増やす。

1. テクスチャの先読みを、アトラス作成後に退避対象となった元画像の除外と、実際に再読み込みされた画像の優先処理に対応させる。Waylithの予算と所有権に従い、本MODの再読み込みを需要に算入しない。
2. 既存の起動スクリプトにWaylithのGPU圧縮と、前回の正常ロードから確定したパックの先読みを任意で追加する。
3. 選択中のWaylithキャッシュルート、MODルートのSHA-256接頭辞、インストールIDを使ってパックを選ぶ。確定できないビルドでは従来の発見方式を使う。
4. 通常・高速プレイのP95フレーム間隔とTPSで既存ワーカーの上限を調整する。フェーズやゲーム速度が変わったら計測窓と基準を取り直す。
5. WOWGAGがJIT準備を有効にしている場合は、MoreUseResourcesのJIT準備を休止する。設定は参照専用で扱う。
6. 任意の積極活用プリセットから、アセットパックの共有RAMページ、実ファイル監査、GPU先読みを有効にする。

完了確認は単体・回帰テスト、Release DLL同期、CI、コードレビュー。GPU実機のA/Bはこれらの実装後に行う。
