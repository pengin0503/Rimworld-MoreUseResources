# Rimworld-MoreUseResources

RimWorld 1.7向けに、**余っているCPU・RAM・GPU/VRAMを、ユーザーが選んだタイミングで積極的に利用する**ことを目的としたMODの開発リポジトリです。

> 現状は**設計段階**です。MOD本体は未実装で、Windows実機での動作検証も未完了です。

## 開発方針

- **FPS/TPSやロード時間の高速化は必須条件ではありません。** リソースの積極的な利用そのものを目的とします。
- 起動後・ロード中だけでなく、**タイトル画面、通常プレイ、高速プレイ、ポーズ中、ワールド／キャラバン画面、アイドル時、セーブ中**などを**個別にON/OFF**できる設定を予定しています。
- CPU・RAM・GPUもそれぞれ個別に有効化・制限可能にします。GPUはWaylithの対応APIが確認できた場合のみ実装します。
- 実データの先読み・キャッシュを優先し、単なるRAM予約やCPU/GPU負荷生成は、効果・危険性を明示した**別のオプション**に分離します。
- 安全上限、メモリ圧迫時の自動縮小、状態切替時のキャンセル、セーブ互換性を重視します。

## 基準ゲーム本体

- **Windows 1.7.5011 rev24**
- Cloudflare R2: `rimworld-17/Game-Windows/`（読み取り専用）
- .NET 10 / Waylith CLR

旧版のR2監査資料は参考にしますが、API・挙動は現行Windows版に対して改めて確認します。
